Help & FAQ

To purchase tickets, is required to be logged in. Once you have an account, open an event detail page and select the 'Get Tickets' button. If there is no tickets available, the button will be disabled. Otherwise, you can choose the desired ticket type and quantities, and confirm the purchase. After a successful purchase, you can view your tickets in your user profile page.

Registered users can edit their profile information, manage their profile image and view their purchased tickets from the user page. If you are not a registered user, you can create an account by clicking the 'Sign Up' button in the header and filling out the registration form. If you already have an account, click the 'Log In' button and enter your credentials to access your profile and manage your account settings.

Anonymous users can browse events and check their details, but they cannot purchase tickets or access certain features without logging in.

Administrator users can create, edit and delete events and participants. They can also upload, update and remove images associated with events and participants.

Registered users can upload profile images from their account page. Administrators can also manage event and participant images. Images are securely stored in the database.

GoEventsNow uses JWT authentication with secure cookies to protect user sessions and private operations. Some features require users to be authenticated before accessing them.

If the application does not load correctly, try refreshing the page, checking your internet connection or logging in again. If the issue persists, contact support.

The application works correctly in modern browsers such as Google Chrome, Microsoft Edge and Mozilla Firefox. During local execution, browsers may display a warning due to the self-signed HTTPS certificate.

For additional support, open an issue in the GitHub repository of the project.
